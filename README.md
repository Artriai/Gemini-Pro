# Gemini Pro

面向 Android 的 Google AI Studio WebView 客户端，基于 [RxNaison/Gemini-Pro](https://github.com/RxNaison/Gemini-Pro) 开发。

直接使用 AI Studio 网页及 Google 账号，不需要在应用中配置 API Key。模型、额度和付费状态由 Google AI Studio 提供。

## 使用

1. 首次使用时，先在 Chrome 中登录 [Google AI Studio](https://aistudio.google.com/)，按网页提示完成 Google Drive 授权。
2. 打开应用并登录 Google 账号。Chrome 与应用的登录状态不共享，网页要求时仍需登录。
3. 首页直接选择模型、思考强度和临时对话，输入草稿后点击发送。应用在后台准备网页，确认配置、写入草稿，并观察网页收到这条消息后进入聊天。
4. 首页左上菜单可打开历史对话或应用工具。聊天界面的角落菜单可返回首页；从顶部中间向下拖动超过阈值再松手可刷新网页。

首页由 Android 本地绘制，不依赖网络响应；网页在它背后准备。模型列表来自网页，首次连接后缓存供下次选择；切换模型会重新读取该模型的思考选项。不会在本地编造模型或推理档位。

进程存活时保留已打开的 WebView，切回聊天不主动刷新。发起新对话或修改模型、临时模式时会按需要准备新的网页。系统结束进程后恢复浏览历史或最近页面再连接 Google，无法把 Google 服务离线化。Google 限制的登录或授权步骤仍需在支持的浏览器中完成。

普通首页草稿保存在应用私有存储中；临时对话草稿只留在当前进程内，退出进程后不恢复，也不参与备份。点击附件会先应用配置、带入草稿，再打开网页的附件入口，尚不会发送。麦克风使用系统语音输入服务（如设备支持）。

网页设置必须能够读取并确认，临时模式也需有真实页面标记；仅有 URL 参数不算确认成功。页面结构改变或配置不支持时保留草稿并停止发送，可打开正常网页处理。提交前写入防重复标记；如果页面跳转、应用被结束或发送回执不明确，先显示聊天供用户检查，不自动重发。

## 功能

- 复制 Mermaid 或 HTML 后显示预览入口，支持 Markdown 代码围栏与说明文字中的代码块。
- 保存剪贴板文本，长按图片下载，开启视频选择模式后长按视频下载。
- 分享页面、复制链接、浏览器打开、前进与刷新。
- 访问 Google Docs 和 Google Flow，按需开启屏幕常亮。
- 简体中文与英文界面，跟随系统语言。

## 本分支改进

- 摄像头和麦克风按需申请：校验网站来源并展示网站授权提示，不在启动时集中申请权限。
- 下载桥接使用限定 HTTPS 来源的 Web Message，仅接受主框架消息与用户发起的下载。
- Blob 下载以 48 KiB 分块传输，在后台写入临时文件，核对长度后保存；支持取消及失败清理，不再禁用 Blob 释放。
- Android 10 及以上使用 MediaStore 保存；Android 9 及以下在下载时申请存储权限。
- 断网重试返回出错页面；刷新错误页也会重试原地址。
- 补齐剪贴板监听与 WebView 清理，避免旧预览计时器提前隐藏新提示。
- 更新来源指向本仓库。
- 复用进程内已打开的页面；聊天界面返回键回到本地首页，首页返回键退至后台；进程恢复时尝试恢复浏览历史。
- 接受站点 Cookie 并在进入后台时写入 WebView 的持久存储，不另行导出登录凭据。
- 深色本地首页替代启动时的整页加载画面，直接显示模型选择、思考强度、临时对话和草稿框。
- 提交前验证网页配置和草稿，使用唯一提交标识与发送回执防止重复点击、界面重建或恢复时重复发消息。

Blob / data 下载暂设 **256 MiB** 上限，一次传输一个文件，页面导航会取消未完成的传输。需要支持 Web Message Listener 的 Android System WebView；过旧版本会提示更新。普通 HTTPS 下载交给系统下载管理器。

Mermaid 运行库目前从 jsDelivr 加载，需要网络。应用界面的中文翻译不改变 Google 网页本身的语言。

## 构建与验证

使用 JDK 21、Android Studio 以及项目指定的 Android SDK / Gradle 版本：

Debug 测试包使用独立包名，可与上游原版共存；不会读取原版的登录状态或设置。

```bash
./gradlew clean testDebugUnitTest lintDebug assembleDebug
npm ci
npm test
```

测试覆盖精确来源匹配、Blob 来源限制、代码围栏提取、Mermaid 文本转义，以及下载的分块完整性、大小限制和取消清理。首页网页适配器通过受控 DOM fixture 验证模型/思考选项读取、配置不匹配阻断、临时模式确认、草稿完整性与重复发送防护。fixture 不是已登录 Google 页面的真实录制；真实账号的模型设置、临时对话、发送、登录、摄像头和系统文件选择仍需 Android 实机验证。Google 页面可能更新，适配器失配时会停止自动提交并保留草稿。
